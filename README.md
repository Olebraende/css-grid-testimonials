# Testimonials grid section

My solution to the [Testimonials grid section challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/testimonials-grid-section-Nnw6J7Un7).

**Live site:** https://olebraende.github.io/css-grid-testimonials/

## The challenge

View the optimal layout for the site depending on the device's screen size.

## Built with

- Semantic HTML5 (`main`, `article`, `blockquote`, `cite`)
- CSS custom properties for the colour palette
- CSS Grid, mobile-first (1 column on mobile, 4 columns from 1000px)
- Reusable background classes (`.bg-purple`, `.bg-grey`, `.bg-dark`, `.bg-white`)

## What I learned

- Placing cards of different sizes with explicit `grid-column` and `grid-row` values
- Giving the cards a 3D look with layered `box-shadow` and a thicker bottom border
- Using `rem` units so text respects the user's browser settings
